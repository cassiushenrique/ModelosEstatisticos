Análise discriminante quadrática (QDA)

Classificador generativo que permite uma matriz de covariância distinta por classe, produzindo fronteiras quadráticas.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Classificador generativo que permite uma matriz de covariância distinta por classe, produzindo fronteiras quadráticas.

02 · Quais são os pressupostos e como verificá-los?

Independência; normalidade multivariada condicional; estimativa não singular de covariâncias por classe (nₖ deve superar p de forma confortável); avaliar overfitting.

03 · Qual a estatística de teste?

Hipóteses

Não possui teste de significância intrínseco para o algoritmo preditivo.

Estatística, estimador ou critério

δₖ(x)=−½ln|Σₖ|−½(x−μₖ)ᵀΣₖ⁻¹(x−μₖ)+lnπₖ; desempenho fora da amostra.

04 · Como interpretar o resultado, supondo 5% de significância?

Compare erros de classificação com LDA usando as mesmas partições. p < 0,05 não substitui validação externa.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: MASS. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Classificar veículos por cilindrada (4/6/8) usando massa e potência em mtcars.

R · script reproduzível
if (!requireNamespace("MASS", quietly = TRUE)) install.packages("MASS")
library(MASS)
set.seed(2026)
d <- transform(mtcars, classe = factor(cyl))
# Treino estratificado para manter cada classe.
i <- unlist(lapply(split(seq_len(nrow(d)), d$classe),
                  function(z) sample(z, max(5, length(z) - 2))))
ajuste <- qda(classe ~ wt + hp, data = d[i, ])
prev <- predict(ajuste, newdata = d[-i, ])
print(table(real = d$classe[-i], previsto = prev$class))

Como interpretar o exemplo

QDA estima uma dispersão distinta para cada grupo. Em classes pequenas, estimativas instáveis exigem regularização ou métodos mais parcimoniosos.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
