Compromisso viés–variância

Modelos muito rígidos podem ter alto viés; modelos muito flexíveis, alta variância preditiva. Regularização e validação controlam o compromisso.

01 · O que é?

Modelos muito rígidos podem ter alto viés; modelos muito flexíveis, alta variância preditiva. Regularização e validação controlam o compromisso.

02 · Quais são os pressupostos e como verificá-los?

Definir distribuição de treinamento e teste, métrica de perda e procedimentos comparáveis; não confundir variância de estimadores com variância amostral dos dados.

03 · Qual a estatística de teste?

Hipóteses

Sem teste H₀ geral.

Estatística, estimador ou critério

Para erro quadrático: E[(Y−f̂(X))² | X=x] = Var(ε)+Viés²+Var(f̂), sob modelo aditivo adequado.

04 · Como interpretar o resultado, supondo 5% de significância?

O melhor compromisso minimiza risco esperado fora da amostra; não é decidido por p < 0,05.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Utiliza funções disponíveis na instalação padrão do R. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Predição da distância de frenagem com polinômios de diferentes graus sobre cars, usando 5-fold CV.

R · script reproduzível
set.seed(2026)
k <- 5; fold <- sample(rep(1:k, length.out = nrow(cars)))
erros <- sapply(1:6, function(grau) {
  pred <- rep(NA_real_, nrow(cars))
  for (j in 1:k) {
    mod <- lm(dist ~ poly(speed, grau, raw = TRUE),
              data = cars[fold != j, ])
    pred[fold == j] <- predict(mod, cars[fold == j, ])
  }
  sqrt(mean((cars$dist - pred)^2))
})
print(data.frame(grau = 1:6, RMSE_CV = erros))

Como interpretar o exemplo

A menor RMSE_CV representa o grau preferido nesta divisão. Crescimento do grau não garante melhor previsão; o risco de overfitting aumenta.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
