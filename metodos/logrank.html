Teste log-rank

Compara funções de risco/sobrevivência entre grupos usando eventos observados e esperados ao longo dos tempos.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Compara funções de risco/sobrevivência entre grupos usando eventos observados e esperados ao longo dos tempos.

02 · Quais são os pressupostos e como verificá-los?

Unidades independentes; censura independente condicional; interpretação de potência favorece alternativas com riscos proporcionais.

03 · Qual a estatística de teste?

Hipóteses

H₀: funções de risco iguais entre grupos; H₁: há diferença.

Estatística, estimador ou critério

χ²=(O₁−E₁)²/V sob dois grupos; generalização para k grupos com k−1 gl.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05: evidência de diferenças entre grupos; não estima direção nem HR e não garante proporcionalidade.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: survival. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Comparação de curvas de tempo até evento por sexo em survival::lung (analogia à comparação de grupos de equipamentos).

R · script reproduzível
if (!requireNamespace("survival", quietly = TRUE)) install.packages("survival")
library(survival)
resultado <- survdiff(Surv(time, status == 2) ~ sex,
                     data = lung, rho = 0)
print(resultado)
p <- pchisq(resultado$chisq, df = length(resultado$n) - 1,
            lower.tail = FALSE)
print(p)

Como interpretar o exemplo

O p-valor verifica igualdade das curvas sob o teste log-rank. Diferenças numéricas devem ser interpretadas junto às estimativas Kaplan–Meier e IC.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

INTERPRETAÇÃO RIGOROSA

p ≥ 0,05 não prova a hipótese nula. Distinga significância estatística, magnitude e precisão. Métodos preditivos sem teste próprio devem ser avaliados fora do treino.
