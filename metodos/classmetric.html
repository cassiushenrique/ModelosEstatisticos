Métricas de classificação e curva ROC

Quantifica desempenho preditivo de classes/probabilidades com acurácia, sensibilidade, especificidade, precisão e AUC.

01 · O que é?

Quantifica desempenho preditivo de classes/probabilidades com acurácia, sensibilidade, especificidade, precisão e AUC.

02 · Quais são os pressupostos e como verificá-los?

Partição de teste representativa, classe positiva definida, limiar de decisão especificado, prevalência e custo de erros considerados; calibrar probabilidades.

03 · Qual a estatística de teste?

Hipóteses

Não há hipótese nula intrínseca à matriz de confusão; H₀:AUC=0,5 requer teste específico e independência apropriada.

Estatística, estimador ou critério

Sensibilidade=VP/(VP+FN); especificidade=VN/(VN+FP); AUC é probabilidade de ordenar um positivo acima de um negativo.

04 · Como interpretar o resultado, supondo 5% de significância?

A 5%, só se rejeita uma hipótese com procedimento formal; para escolher classificador, priorize erro externo e custo de falsos negativos/positivos.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Utiliza funções disponíveis na instalação padrão do R. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Classificar transmissão manual (am=1) com massa e potência (mtcars).

R · script reproduzível
set.seed(2026)
i <- sample.int(nrow(mtcars), 22)
ajuste <- glm(am ~ wt + hp, data = mtcars[i, ],
              family = binomial())
prob <- predict(ajuste, newdata = mtcars[-i, ], type = "response")
prev <- as.integer(prob >= 0.5)
tab <- table(real = factor(mtcars$am[-i], levels = 0:1),
             previsto = factor(prev, levels = 0:1))
print(tab)
print(sum(diag(tab)) / sum(tab))

Como interpretar o exemplo

Acurácia deve ser comparada ao classificador majoritário. Em defeitos raros na indústria, sensibilidade/precisão e curva PR são frequentemente mais informativas.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
