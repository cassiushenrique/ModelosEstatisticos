Regressão linear simples

Relaciona a resposta contínua Y a um preditor X: \(\mathbb E(Y\mid X=x)=\beta_0+\beta_1x\). Os coeficientes de mínimos quadrados minimizam a soma dos resíduos ao quadrado.

01 · O que é?

Relaciona a resposta contínua Y a um preditor X: \(\mathbb E(Y\mid X=x)=\beta_0+\beta_1x\). Os coeficientes de mínimos quadrados minimizam a soma dos resíduos ao quadrado.

02 · Quais são os pressupostos e como verificá-los?

Independência dos erros, média condicional linear, ausência de pontos excessivamente influentes; homocedasticidade para erros-padrão usuais, normalidade dos erros para inferência exata em amostras pequenas. Verifique \(\text{resíduos}\times\text{valores ajustados}\), Q–Q e influência.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

\(H_0\): \(\beta_{1}=0\); \(H_1\): \(\beta_{1}\neq0\).

Estatística de teste, estimador ou critério de otimização

\[Y_i=\beta_0+\beta_1x_i+\varepsilon_i,\qquad t=\frac{\widehat\beta_1}{\operatorname{EP}(\widehat\beta_1)}\]

Intervalo de confiança de 95% (quando aplicável)

\[IC_{95\%}(\beta_1)=\widehat\beta_1\pm t_{0{,}975;n-2}\operatorname{EP}(\widehat\beta_1)\]

04 · Como interpretar o resultado, supondo 5% de significância?

\(p<0{,}05\): evidência de associação linear condicional. \(IC_{95\%}\) para \(\beta_{1}\); IC da média e intervalo de predição são objetos distintos.

05 · Como executar no R?

Usa funções da instalação padrão do R. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Distância de frenagem (dist) em função da velocidade (speed) de automóveis (cars).

R · executar o bloco completo
ajuste <- lm(dist ~ speed, data = cars)
print(summary(ajuste))
print(confint(ajuste, level = 0.95))
print(predict(ajuste, newdata = data.frame(speed = 20),
              interval = "prediction", level = 0.95))
plot(ajuste, which = 1)

Interpretação do exemplo

O coeficiente de speed indica a variação média estimada em dist para uma unidade adicional de velocidade. Use o intervalo de predição para uma nova observação; ele é mais largo que o IC da média.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.

CRITÉRIO DE DECISÃO

\(p\geq0{,}05\) não prova a hipótese nula. Para modelos sem teste intrínseco, avalie o erro de predição e a estabilidade com dados não utilizados no ajuste.
