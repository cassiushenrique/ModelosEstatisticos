Hochberg GT2

Procedimento de comparações múltiplas para tamanhos amostrais desiguais sob homocedasticidade; baseado na distribuição do módulo máximo studentizado.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Procedimento de comparações múltiplas para tamanhos amostrais desiguais sob homocedasticidade; baseado na distribuição do módulo máximo studentizado.

02 · Quais são os pressupostos e como verificá-los?

Independência, normalidade e variância residual comum; tamanhos desiguais podem motivar GT2, sem justificar ignorar heterocedasticidade.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

\(H_{0,ij}\): \(\mu_{i}=\mu_{j}\) para todos os pares.

Estatística de teste, estimador ou critério de otimização

\[T_{ij}=\frac{\bar Y_i-\bar Y_j}{S_p\sqrt{1/n_i+1/n_j}}\quad\text{(crítico do máximo studentizado)}\]

Estatísticas t padronizadas e distribuição crítica do módulo máximo studentizado, com ajuste para os n dos grupos.

04 · Como interpretar o resultado, supondo 5% de significância?

Diferença detectada quando contraste excede crítico simultâneo. GT2 não é equivalente ao ajuste step-up de Hochberg para p-valores.

05 · Como executar no R?

Usa funções da instalação padrão do R. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Tensões de fiação em warpbreaks. É mostrado um método substituto implementado diretamente, não o GT2 exato.

R · executar o bloco completo
# Alternativa reproduzível com controle FWER: Holm sobre t de Welch.
# Isto NÃO implementa exatamente Hochberg GT2.
resultado <- pairwise.t.test(warpbreaks$breaks, warpbreaks$tension,
                          pool.sd = FALSE, p.adjust.method = "holm")
print(resultado)

Interpretação do exemplo

Use Holm como alternativa para comparações pareadas quando não dispuser de implementação GT2 confiável. O p-valor produzido não deve ser publicado como “GT2”.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.

Nota metodológica

Não foi identificada implementação R/CRAN do GT2 exato suficientemente validada nesta elaboração. O exemplo implementa e identifica uma alternativa, sem equiparação indevida.

Nota metodológica

O exemplo utiliza aproximação computacional explicitada no script; não a interprete como implementação exata de Hochberg GT2.
