Smoothing splines

Estima uma curva suave penalizando o excesso de curvatura, em vez de selecionar manualmente todos os nós.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Estima uma curva suave penalizando o excesso de curvatura, em vez de selecionar manualmente todos os nós.

02 · Quais são os pressupostos e como verificá-los?

Observações representativas, suavidade plausível e escolha de penalização por GCV/CV; avaliar bordas e extrapolação.

03 · Qual a estatística de teste?

Hipóteses

Não há teste H₀ universal no ajuste por smooth.spline; comparações requerem procedimentos específicos.

Estatística, estimador ou critério

Minimiza ∑(yᵢ−f(xᵢ))² + λ∫[f″(t)]²dt; λ selecionado por critério de predição.

04 · Como interpretar o resultado, supondo 5% de significância?

O parâmetro df efetivo reflete complexidade. Decisões via desempenho/diagnóstico, não via p<0,05 automático.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Utiliza funções disponíveis na instalação padrão do R. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Relação velocidade–distância de frenagem em cars.

R · script reproduzível
ajuste <- smooth.spline(cars$speed, cars$dist, cv = FALSE)
print(c(df_efetivo = ajuste$df, spar = ajuste$spar))
plot(dist ~ speed, data = cars)
lines(ajuste, col = "red", lwd = 2)

Como interpretar o exemplo

A curva suavizada é estimada com penalização de rugosidade; o df efetivo cresce quando há maior flexibilidade.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
