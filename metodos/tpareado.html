Teste t pareado

Compara a média das diferenças Dᵢ=Yᵢ,depois−Yᵢ,antes em pares correspondentes.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Compara a média das diferenças Dᵢ=Yᵢ,depois−Yᵢ,antes em pares correspondentes.

02 · Quais são os pressupostos e como verificá-los?

Pares corretamente identificados; pares independentes entre si; distribuição aproximadamente normal das diferenças em amostras pequenas. Não é necessário que cada condição isolada seja normal.

03 · Qual a estatística de teste?

Hipóteses

H₀: μ_D=0; H₁: μ_D≠0.

Estatística, estimador ou critério

t = d̄/(s_D/√n), gl=n−1.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05: evidência de diferença média; IC95% para μ_D exclui 0.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Utiliza funções disponíveis na instalação padrão do R. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Comparar a absorção de CO₂ da mesma planta em duas concentrações (dados CO2; bioprocessos).

R · script reproduzível
d <- subset(CO2, conc %in% c(95, 175))
wide <- reshape(d[, c("Plant", "conc", "uptake")], idvar = "Plant",
                timevar = "conc", direction = "wide")
resultado <- t.test(wide$uptake.175, wide$uptake.95,
                    paired = TRUE, conf.level = 0.95)
print(resultado)
qqnorm(wide$uptake.175 - wide$uptake.95); qqline(wide$uptake.175 - wide$uptake.95)

Como interpretar o exemplo

O IC95% refere-se à média da variação de absorção 175−95 para a mesma planta. A dependência dentro da planta é preservada no pareamento.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

INTERPRETAÇÃO RIGOROSA
