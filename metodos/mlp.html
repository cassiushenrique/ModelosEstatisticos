Rede neural multicamadas (MLP)

Modelo supervisionado que combina transformações lineares e ativações não lineares em camadas ocultas para regressão ou classificação.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Modelo supervisionado que combina transformações lineares e ativações não lineares em camadas ocultas para regressão ou classificação.

02 · Quais são os pressupostos e como verificá-los?

Pré-processamento aprendido no treino, definição de arquitetura, regularização, múltiplas inicializações e validação; forte sensibilidade a n pequeno.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

Sem \(H_0\) geral intrínseca ao treinamento; métricas preditivas substituem interpretação de p-valores usuais.

Estatística de teste, estimador ou critério de otimização

\[\mathbf h=\phi(\mathbf W_1\mathbf x+\mathbf b_1),\quad\widehat y=g(\mathbf W_2\mathbf h+\mathbf b_2)\]

Minimiza erro quadrático ou entropia cruzada por retropropagação, com regularização; RMSE/AUC externamente.

04 · Como interpretar o resultado, supondo 5% de significância?

Menor erro validado indica melhor predição; pesos internos não devem ser interpretados como efeitos independentes simples.

05 · Como executar no R?

Pacotes adicionais: nnet. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Predição da autonomia por massa, potência e cilindrada (mtcars).

R · executar o bloco completo
if (!requireNamespace("nnet", quietly = TRUE)) install.packages("nnet")
library(nnet)
set.seed(2026)
d <- mtcars[, c("mpg", "wt", "hp", "disp")]
d[] <- lapply(d, function(v) as.numeric(scale(v)))
i <- sample.int(nrow(d), 22)
ajuste <- nnet(mpg ~ wt + hp + disp, data = d[i, ],
              size = 3, linout = TRUE, decay = 0.01,
              maxit = 800, trace = FALSE)
pred <- as.numeric(predict(ajuste, d[-i, ]))
print(sqrt(mean((d$mpg[-i] - pred)^2)))

Interpretação do exemplo

O RMSE está na escala padronizada de mpg, pois a resposta foi padronizada; para unidades originais reverta a transformação com parâmetros estimados no treino.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.

Nota metodológica

Para avaliação externa estrita, ajuste os parâmetros de padronização exclusivamente no treino (o código é uma demonstração compacta de arquitetura).
