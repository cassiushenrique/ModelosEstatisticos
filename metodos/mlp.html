02 · Pressupostos e como verificá-los

  • Pré-processamento aprendido no treino, definição de arquitetura, regularização, múltiplas inicializações e validação.
  • Forte sensibilidade a n pequeno.

Confira o delineamento da pesquisa e os gráficos exploratórios. A validade inferencial depende dos pressupostos do modelo, não apenas do resultado de um teste diagnóstico.

03 · Hipóteses e estatística de teste

Hipóteses

Não há teste de hipótese nula intrínseco a este procedimento. A avaliação deve considerar o objetivo de estimação, a incerteza apropriada ou o desempenho em dados não utilizados no ajuste.

Estatística, estimador ou critério de ajuste

\[\mathbf h=\phi(\mathbf W_1\mathbf x+\mathbf b_1),\quad\widehat y=g(\mathbf W_2\mathbf h+\mathbf b_2)\]

Em que:

\(\mathbf x\)
vetor de entradas
\(\mathbf W\)
matriz de pesos ajustáveis
\(\phi\)
função de ativação
\(\widehat y\)
saída predita pela rede

Minimiza erro quadrático ou entropia cruzada por retropropagação, com regularização; RMSE/AUC externamente.

Os valores amostrais são obtidos diretamente dos dados; os estimadores, pesos ou coeficientes específicos são calculados pelas funções do R indicadas no exemplo. Não substitua parâmetros desconhecidos por valores arbitrários.

04 · Como interpretar os resultados?

Menor erro validado indica melhor predição; pesos internos não devem ser interpretados como efeitos independentes simples.

Priorize o desempenho preditivo ou a estabilidade do ajuste. Quando não houver teste intrínseco, não interprete a métrica como valor-p nem aplique automaticamente o nível de 5%.

06 · Exemplo de aplicação

Contexto dos dados

O conjunto mtcars reúne atributos de 32 modelos de automóveis, incluindo consumo, potência e massa.

Objetivo da análise

Predição da autonomia por massa, potência e cilindrada (mtcars).

R · executar o bloco completo 
# Rede neural multicamadas (MLP) ----

# Ajuste e resultados ----
if (!requireNamespace("nnet", quietly = TRUE)) install.packages("nnet")
library(nnet)
set.seed(2026)
d <- mtcars[, c("mpg", "wt", "hp", "disp")]
d[] <- lapply(d, function(v) as.numeric(scale(v)))
i <- sample.int(nrow(d), 22)
ajuste <- nnet(mpg ~ wt + hp + disp, data = d[i, ],
              size = 3, linout = TRUE, decay = 0.01,
              maxit = 800, trace = FALSE)
pred <- as.numeric(predict(ajuste, d[-i, ]))
print(sqrt(mean((d$mpg[-i] - pred)^2)))

# Visualização e diagnóstico ----
plot(mtcars$wt, mtcars$hp, col = factor(mtcars$cyl), pch = 19, xlab = "Massa (mil libras)", ylab = "Potência", main = "Características e classes de veículos")

A saída numérica e os gráficos deste exemplo devem ser conferidos na execução do script R; não foram reproduzidos neste ambiente.

Resultados e interpretação

O código apresenta uma sugestão de aplicação; a análise deve ser adaptada aos dados e ao objetivo do estudo.

Nota metodológica

Para avaliação externa estrita, ajuste os parâmetros de padronização exclusivamente no treino (o código é uma demonstração compacta de arquitetura).
