Regressão ridge

Encolhe coeficientes de regressão via penalidade quadrática; reduz variância em presença de preditores correlacionados, sem tipicamente zerar coeficientes.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Encolhe coeficientes de regressão via penalidade quadrática; reduz variância em presença de preditores correlacionados, sem tipicamente zerar coeficientes.

02 · Quais são os pressupostos e como verificá-los?

Padronizar preditores, definir λ por validação interna e separar teste externo; independência/média condicional bem representada.

03 · Qual a estatística de teste?

Hipóteses

H₀ para βⱼ não possui teste t usual após penalização; inferência requer métodos específicos.

Estatística, estimador ou critério

Minimiza RSS(β)+λ∑βⱼ², com intercepto não penalizado; λ por CV.

04 · Como interpretar o resultado, supondo 5% de significância?

Compare RMSE externo; coeficientes ridge não têm IC/t padrão do OLS sem adaptação.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: glmnet. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Predição de autonomia por massa, potência, cilindrada e aceleração (mtcars).

R · script reproduzível
if (!requireNamespace("glmnet", quietly = TRUE)) install.packages("glmnet")
library(glmnet)
set.seed(2026)
x <- model.matrix(mpg ~ wt + hp + disp + qsec, mtcars)[, -1]
y <- mtcars$mpg
ajuste <- cv.glmnet(x, y, alpha = 0, nfolds = 5)
print(ajuste$lambda.min)
print(coef(ajuste, s = "lambda.min"))

Como interpretar o exemplo

O parâmetro λ selecionado controla a contração. A vantagem deve ser avaliada pelo erro em dados não usados para seleção de λ.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
