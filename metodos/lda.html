Análise discriminante linear (LDA)

Classificador generativo que assume distribuições normais multivariadas por classe com matriz de covariância comum.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Classificador generativo que assume distribuições normais multivariadas por classe com matriz de covariância comum.

02 · Quais são os pressupostos e como verificá-los?

Observações independentes, covariáveis quantitativas, normalidade condicional aproximada e matriz de covariância comum não singular; avaliar outliers e desempenho em teste.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

Não há \(H_0\) único para LDA preditiva; testes de igualdade de médias podem ser formulados separadamente.

Estatística de teste, estimador ou critério de otimização

\[\delta_k(\mathbf x)=\mathbf x^\top\boldsymbol\Sigma^{-1}\boldsymbol\mu_k-\frac12\boldsymbol\mu_k^\top\boldsymbol\Sigma^{-1}\boldsymbol\mu_k+\ln\pi_k\]

04 · Como interpretar o resultado, supondo 5% de significância?

A classificação depende da maior função discriminante/posterior; \(p<0{,}05\) não é critério intrínseco de qualidade preditiva.

05 · Como executar no R?

Pacotes adicionais: MASS. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Classificar veículos por quantidade de cilindros usando potência e massa em mtcars.

R · executar o bloco completo
if (!requireNamespace("MASS", quietly = TRUE)) install.packages("MASS")
library(MASS)
set.seed(2026)
d <- transform(mtcars, classe = factor(cyl))
i <- sample(seq_len(nrow(d)), 22)
ajuste <- lda(classe ~ wt + hp, data = d[i, ])
prev <- predict(ajuste, newdata = d[-i, ])
print(table(real = d$classe[-i], previsto = prev$class))

Interpretação do exemplo

A matriz de confusão avalia erros em veículos fora do treinamento. A amostra é pequena; um único particionamento tem grande incerteza.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.
