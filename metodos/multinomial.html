Regressão logística multinomial

Classifica respostas com três ou mais categorias nominais, modelando logits relativos a uma categoria de referência.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Classifica respostas com três ou mais categorias nominais, modelando logits relativos a uma categoria de referência.

02 · Quais são os pressupostos e como verificá-los?

Categorias mutuamente exclusivas; observações independentes; especificação linear dos logits, sem separação, amostra suficiente para parâmetros. A hipótese de independência das alternativas irrelevantes exige justificativa conforme o problema.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

\(H_{0,jk}\): \(\beta_{jk}=0\), para preditor j e categoria k contra a referência; teste global por deviance quando adequado.

Estatística de teste, estimador ou critério de otimização

\[\log\frac{\Pr(Y=k\mid\mathbf x)}{\Pr(Y=K\mid\mathbf x)}=\beta_{0k}+\mathbf x^\top\boldsymbol\beta_k\]

04 · Como interpretar o resultado, supondo 5% de significância?

\(p<0{,}05\) indica evidência de efeito no logito relativo; \(\exp(\beta)\) não é aumento direto de probabilidade de uma categoria.

05 · Como executar no R?

Pacotes adicionais: nnet. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Previsão do número de cilindros (4, 6, 8) a partir da massa e potência (mtcars).

R · executar o bloco completo
if (!requireNamespace("nnet", quietly = TRUE)) install.packages("nnet")
library(nnet)
d <- transform(mtcars, cyl = factor(cyl))
ajuste <- multinom(cyl ~ wt + hp, data = d, trace = FALSE)
print(summary(ajuste))
print(head(predict(ajuste, type = "probs")))
print(table(real = d$cyl, previsto = predict(ajuste)))

Interpretação do exemplo

As probabilidades previstas somam 1 para cada veículo. Compare as três categorias e observe que o conjunto é pequeno para inferência estável.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.

CRITÉRIO DE DECISÃO

\(p\geq0{,}05\) não prova a hipótese nula. Para modelos sem teste intrínseco, avalie o erro de predição e a estabilidade com dados não utilizados no ajuste.
