Regressão logística multinomial

Classifica respostas com três ou mais categorias nominais, modelando logits relativos a uma categoria de referência.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Classifica respostas com três ou mais categorias nominais, modelando logits relativos a uma categoria de referência.

02 · Quais são os pressupostos e como verificá-los?

Categorias mutuamente exclusivas; observações independentes; especificação linear dos logits, sem separação, amostra suficiente para parâmetros. A hipótese de independência das alternativas irrelevantes exige justificativa conforme o problema.

03 · Qual a estatística de teste?

Hipóteses

H₀ⱼₖ: βⱼₖ = 0, para preditor j e categoria k contra a referência; teste global por deviance quando adequado.

Estatística, estimador ou critério

Wald z por coeficiente; G² entre modelos aninhados (χ² assintótico); exp(β) = razão de razões de probabilidade relativas.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05 indica evidência de efeito no logito relativo; exp(β) não é aumento direto de probabilidade de uma categoria.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: nnet. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Previsão do número de cilindros (4, 6, 8) a partir da massa e potência (mtcars).

R · script reproduzível
if (!requireNamespace("nnet", quietly = TRUE)) install.packages("nnet")
library(nnet)
d <- transform(mtcars, cyl = factor(cyl))
ajuste <- multinom(cyl ~ wt + hp, data = d, trace = FALSE)
print(summary(ajuste))
print(head(predict(ajuste, type = "probs")))
print(table(real = d$cyl, previsto = predict(ajuste)))

Como interpretar o exemplo

As probabilidades previstas somam 1 para cada veículo. Compare as três categorias e observe que o conjunto é pequeno para inferência estável.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

INTERPRETAÇÃO RIGOROSA
