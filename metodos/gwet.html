Coeficiente AC1 de Gwet

Medida de concordância nominal que usa correção para acordo casual distinta da empregada no Kappa, menos sujeita a alguns paradoxos de prevalência.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Medida de concordância nominal que usa correção para acordo casual distinta da empregada no Kappa, menos sujeita a alguns paradoxos de prevalência.

02 · Quais são os pressupostos e como verificá-los?

Classificações nominais para as mesmas unidades; avaliadores comparáveis; reportar margens, acordo observado e definição de chance.

03 · Qual a estatística de teste?

Hipóteses

H₀: AC1=0 em inferência padrão do pacote; H₁: ≠0.

Estatística, estimador ou critério

AC1=(Pₒ−Pₑ*)/(1−Pₑ*), com Pₑ* definido pelo modelo de acordo casual de Gwet.

04 · Como interpretar o resultado, supondo 5% de significância?

Interprete coeficiente, IC95% e relevância metrológica; p < 0,05 isolado não demonstra concordância satisfatória.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: irrCAC. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Sistemas de triagem de veículos em alto/baixo consumo obtidos de mpg e potência (mtcars), apenas para cálculo didático.

R · script reproduzível
if (!requireNamespace("irrCAC", quietly = TRUE)) install.packages("irrCAC")
library(irrCAC)
ratings <- data.frame(
  A = ifelse(mtcars$mpg < median(mtcars$mpg), "alto", "baixo"),
  B = ifelse(mtcars$hp > median(mtcars$hp), "alto", "baixo"))
print(gwet.ac1.raw(ratings, conflev = 0.95)$est)

Como interpretar o exemplo

Compare AC1 com κ quando houver forte desequilíbrio de categorias, mas explicite que empregam modelos diferentes de concordância por acaso.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
