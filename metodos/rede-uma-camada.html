Rede sem camada oculta (classificador logístico)

Rede com entradas conectadas diretamente à saída sigmoide. Sem camadas ocultas, é equivalente à regressão logística para resposta binária e perda logarítmica.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Rede com entradas conectadas diretamente à saída sigmoide. Sem camadas ocultas, é equivalente à regressão logística para resposta binária e perda logarítmica.

02 · Quais são os pressupostos e como verificá-los?

Codificação adequada da resposta, escalonamento/estabilidade numérica, amostras representativas e validação; para inferência, considerar interpretação como GLM.

03 · Qual a estatística de teste?

Hipóteses

Se formulada como GLM logístico, H₀: βⱼ=0 é testável; o treinamento da rede isoladamente não produz teste inferencial convencional.

Estatística, estimador ou critério

Função σ(z)=1/(1+e⁻ᶻ), perda de entropia cruzada; classificação por probabilidades/limiar.

04 · Como interpretar o resultado, supondo 5% de significância?

A 5% a inferência deve usar procedimento inferencial separado. Como rede, avalie log-loss e erro de classificação em teste.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: nnet. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Classificar transmissão manual de veículos (mtcars) usando atributos normalizados.

R · script reproduzível
if (!requireNamespace("nnet", quietly = TRUE)) install.packages("nnet")
library(nnet)
set.seed(2026)
d <- mtcars
d$wt <- as.numeric(scale(d$wt))
d$hp <- as.numeric(scale(d$hp))
d$am <- factor(d$am)
ajuste <- nnet(am ~ wt + hp, data = d, size = 0,
              skip = TRUE, entropy = TRUE, maxit = 500,
              trace = FALSE)
print(table(real = d$am,
            previsto = predict(ajuste, type = "class")))

Como interpretar o exemplo

Com size=0 e skip=TRUE não há camada oculta; este exemplo mostra a relação entre modelos logísticos e redes neurais de uma camada.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
