Coeficiente de concordância de Kendall (W)

Resume a concordância global entre três ou mais conjuntos de rankings dos mesmos objetos.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Resume a concordância global entre três ou mais conjuntos de rankings dos mesmos objetos.

02 · Quais são os pressupostos e como verificá-los?

Todos os avaliadores ordenam os mesmos itens; blocos/itens bem definidos; corrigir empates quando houver; independência dos itens para inferência aproximada.

03 · Qual a estatística de teste?

Hipóteses

H₀: ausência de concordância sistemática nos rankings; H₁: concordância.

Estatística, estimador ou critério

W = 12∑ᵢ(Rᵢ−R̄)²/[m²(n³−n)], sem empates; χ²≈m(n−1)W.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05 indica concordância além do acaso sob modelo nulo; W próximo de 1 é forte acordo, mas não estabelece validade dos critérios.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: irr. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Três critérios simulados de avaliação de potência dos mesmos 32 automóveis (mtcars).

R · script reproduzível
if (!requireNamespace("irr", quietly = TRUE)) install.packages("irr")
library(irr)
set.seed(2026)
ratings <- data.frame(
  avaliador_1 = mtcars$hp + rnorm(32, 0, 8),
  avaliador_2 = mtcars$hp + rnorm(32, 0, 8),
  avaliador_3 = mtcars$hp + rnorm(32, 0, 8))
print(kendall(ratings, correct = TRUE))

Como interpretar o exemplo

W estima quão próximas estão as ordenações dos veículos por três avaliadores simulados. Comparar apenas p-valor ignora a magnitude de acordo.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

Nota metodológica

As avaliações foram simuladas com ruído a partir da potência observada.
