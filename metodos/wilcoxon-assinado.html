Wilcoxon signed-rank (pareado)

Avalia o centro de uma distribuição aproximadamente simétrica de diferenças pareadas sem pressupor normalidade.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Avalia o centro de uma distribuição aproximadamente simétrica de diferenças pareadas sem pressupor normalidade.

02 · Quais são os pressupostos e como verificá-los?

Diferenças entre pares independentes, distribuição aproximadamente simétrica para interpretação como mediana das diferenças; tratamento cuidadoso de zeros e empates.

03 · Qual a estatística de teste?

Hipóteses

H₀: distribuição de D simétrica em torno de zero (ou parâmetro de localização nulo); H₁: localização diferente.

Estatística, estimador ou critério

V = soma dos postos positivos dos |Dᵢ| não nulos.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05: evidência de deslocamento de localização pareada; IC95% de Hodges–Lehmann quando disponível.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Utiliza funções disponíveis na instalação padrão do R. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Diferença de absorção por planta entre duas concentrações de CO₂.

R · script reproduzível
d <- subset(CO2, conc %in% c(95, 175))
w <- reshape(d[, c("Plant", "conc", "uptake")],
             idvar = "Plant", timevar = "conc", direction = "wide")
print(wilcox.test(w$uptake.175, w$uptake.95,
                  paired = TRUE, exact = FALSE,
                  conf.int = TRUE))

Como interpretar o exemplo

O teste usa magnitudes ordenadas das diferenças na mesma planta. Diferença de localização não é automaticamente diferença das medianas marginais.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

INTERPRETAÇÃO RIGOROSA
