Mínimos quadrados ponderados (WLS)

Ajusta regressão linear minimizando \(\sum_iw_i(y_i-\mathbf x_i^\top\boldsymbol\beta)^2\); pesos idealmente proporcionais a \(1/\operatorname{Var}(\varepsilon_i)\).

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Ajusta regressão linear minimizando \(\sum_iw_i(y_i-\mathbf x_i^\top\boldsymbol\beta)^2\); pesos idealmente proporcionais a \(1/\operatorname{Var}(\varepsilon_i)\).

02 · Quais são os pressupostos e como verificá-los?

Independência, linearidade na média; pesos positivos e apropriados à variância condicional; diagnósticos dos resíduos ponderados. Não basta atribuir pesos arbitrários para garantir eficiência.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

\(H_0\): \(\beta_{j}=0\); \(H_1\): \(\beta_{j}\neq0\) sob modelo ponderado correto.

Estatística de teste, estimador ou critério de otimização

\[\widehat{\boldsymbol\beta}_{\mathrm{MQP}}=(\mathbf X^\top\mathbf W\mathbf X)^{-1}\mathbf X^\top\mathbf W\mathbf Y\]

t de coeficientes e F global com erros-padrão apropriados aos pesos, quando as hipóteses se sustentam.

04 · Como interpretar o resultado, supondo 5% de significância?

\(p<0{,}05\) indica associação na regressão ponderada; \(IC_{95\%}\) depende da validade dos pesos.

05 · Como executar no R?

Usa funções da instalação padrão do R. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Distância de frenagem segundo velocidade (cars), usando ponderação demonstrativa inversa ao quadrado da velocidade.

R · executar o bloco completo
d <- cars
# Pesos didáticos: supõe Var(erro | speed) proporcional a speed²
w <- 1 / d$speed^2
ajuste <- lm(dist ~ speed, data = d, weights = w)
print(summary(ajuste)); print(confint(ajuste))
plot(fitted(ajuste), residuals(ajuste) * sqrt(w),
     xlab = "Ajustados", ylab = "Resíduos ponderados")
abline(h = 0, col = "red")

Interpretação do exemplo

A hipótese sobre a variância foi imposta para ilustração, não demonstrada pelos dados. Os coeficientes são estimados dando menor peso às velocidades maiores.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.

CRITÉRIO DE DECISÃO

\(p\geq0{,}05\) não prova a hipótese nula. Para modelos sem teste intrínseco, avalie o erro de predição e a estabilidade com dados não utilizados no ajuste.
