ANOVA mista

Combina pelo menos um fator entre unidades e um fator intraunidade com medidas repetidas.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Combina pelo menos um fator entre unidades e um fator intraunidade com medidas repetidas.

02 · Quais são os pressupostos e como verificá-los?

Independência entre unidades, medidas correlacionadas dentro da unidade, distribuição de erros adequada, esfericidade no fator intraunidade; examine interação.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

\(H_0\): ausência de efeito do fator entre unidades, do fator intraunidade e de sua interação (hipóteses distintas).

Estatística de teste, estimador ou critério de otimização

\[Y_{ijt}=\mu+\alpha_i+\gamma_t+(\alpha\gamma)_{it}+b_{j(i)}+\varepsilon_{ijt}\]

Estatísticas F com diferentes estratos de erro para termos entre e intraunidade; correções de esfericidade.

04 · Como interpretar o resultado, supondo 5% de significância?

\(p<0{,}05\) para interação indica que perfis temporais/condicionais diferem entre grupos.

05 · Como executar no R?

Pacotes adicionais: ez. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Absorção em plantas de Quebec/Mississippi (Type) ao longo de concentrações de \(CO_{2}\) (conc), com medidas repetidas por Plant.

R · executar o bloco completo
if (!requireNamespace("ez", quietly = TRUE)) install.packages("ez")
library(ez)
d <- CO2
d$conc <- factor(d$conc)
d$Plant <- factor(d$Plant)
resultado <- ezANOVA(data = d, dv = .(uptake), wid = .(Plant),
                     within = .(conc), between = .(Type), detailed = TRUE)
print(resultado)

Interpretação do exemplo

A interação \(\mathrm{Type}\times\mathrm{conc}\) avalia se o perfil de resposta difere entre origens. A planta, não cada medição, é a unidade independente.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.

CRITÉRIO DE DECISÃO

\(p\geq0{,}05\) não prova a hipótese nula. Para modelos sem teste intrínseco, avalie o erro de predição e a estabilidade com dados não utilizados no ajuste.
