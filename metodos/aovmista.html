ANOVA mista

Combina pelo menos um fator entre unidades e um fator intraunidade com medidas repetidas.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Combina pelo menos um fator entre unidades e um fator intraunidade com medidas repetidas.

02 · Quais são os pressupostos e como verificá-los?

Independência entre unidades, medidas correlacionadas dentro da unidade, distribuição de erros adequada, esfericidade no fator intraunidade; examine interação.

03 · Qual a estatística de teste?

Hipóteses

H₀: ausência de efeito do fator entre unidades, do fator intraunidade e de sua interação (hipóteses distintas).

Estatística, estimador ou critério

Estatísticas F com diferentes estratos de erro para termos entre e intraunidade; correções de esfericidade.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05 para interação indica que perfis temporais/condicionais diferem entre grupos.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: ez. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Absorção em plantas de Quebec/Mississippi (Type) ao longo de concentrações de CO₂ (conc), com medidas repetidas por Plant.

R · script reproduzível
if (!requireNamespace("ez", quietly = TRUE)) install.packages("ez")
library(ez)
d <- CO2
d$conc <- factor(d$conc)
d$Plant <- factor(d$Plant)
resultado <- ezANOVA(data = d, dv = .(uptake), wid = .(Plant),
                     within = .(conc), between = .(Type), detailed = TRUE)
print(resultado)

Como interpretar o exemplo

A interação Type×conc avalia se o perfil de resposta difere entre origens. A planta, não cada medição, é a unidade independente.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

INTERPRETAÇÃO RIGOROSA

p ≥ 0,05 não prova a hipótese nula. Distinga significância estatística, magnitude e precisão. Métodos preditivos sem teste próprio devem ser avaliados fora do treino.
