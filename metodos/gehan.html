Teste generalizado de Wilcoxon–Gehan

Compara curvas de sobrevivência, atribuindo maior peso às diferenças em tempos iniciais.

Ver exemplo em R ↓ Baixar script .R ↓

01 · O que é?

Compara curvas de sobrevivência, atribuindo maior peso às diferenças em tempos iniciais.

02 · Pressupostos e como verificá-los

  • Unidades independentes, censura não informativa, tempos e status corretos.
  • Ponderação previamente escolhida.

Confira o delineamento da pesquisa e os gráficos exploratórios. A validade inferencial depende dos pressupostos do modelo, não apenas do resultado de um teste diagnóstico.

03 · Hipóteses e estatística de teste

Hipóteses

\[\left\{\begin{aligned}H_0&:\ S_1(t)=S_2(t)\quad\forall t\\ H_1&:\ \exists\,t:S_1(t)\neq S_2(t)\end{aligned}\right.\]

Estatística, estimador ou critério de ajuste

\[U=\sum_jn(t_j)[O_1(t_j)-E_1(t_j)],\qquad X^2=\frac{U^2}{\operatorname{Var}(U)}\]

Em que:

\(t\)
tempo de acompanhamento
\(S(t)\)
função de sobrevivência
\(n_j\)
número de unidades sob risco no instante j

Os valores amostrais são obtidos diretamente dos dados; os estimadores, pesos ou coeficientes específicos são calculados pelas funções do R indicadas no exemplo. Não substitua parâmetros desconhecidos por valores arbitrários.

04 · Como interpretar os resultados?

\(p<0{,}05\) : evidência de diferença ponderada nas curvas; comparação com log-rank depende do padrão temporal de efeitos.

Considere a censura, a quantidade de unidades sob risco e a precisão das estimativas ao longo do tempo. Em regressão de Cox, interprete razões de taxas instantâneas, não razões de probabilidades.

05 · Como executar no R?

Examine os dados, execute a análise e compare os resultados com os valores e gráficos apresentados a seguir.

Copie o código para o RStudio ou baixe o arquivo .R para executar o exemplo completo.

06 · Exemplo de aplicação

Contexto dos dados

Os dados survival::lung registram tempos de evento e censura.

Objetivo da análise

Comparar distribuições de tempos entre grupos dando peso relativamente maior a eventos mais precoces.

R · executar o bloco completo 
# Teste generalizado de Wilcoxon–Gehan ----

# Ajuste e resultados ----
if (!requireNamespace("survival", quietly = TRUE)) install.packages("survival")
library(survival)
d <- subset(lung, !is.na(time) & !is.na(status) & !is.na(sex))
d$evento <- as.integer(d$status == 2)
d$grupo <- as.integer(d$sex == 2)
U <- 0; V <- 0
for (t in sort(unique(d$time[d$evento == 1]))) {
  risco <- d$time >= t
  evento <- d$time == t & d$evento == 1
  n <- sum(risco); n1 <- sum(risco & d$grupo == 1)
  n0 <- n - n1; dt <- sum(evento)
  o1 <- sum(evento & d$grupo == 1)
  if (n > 1) {
    U <- U + n * (o1 - dt * n1 / n)
    V <- V + n^2 * (n1 * n0 * dt * (n - dt)) / (n^2 * (n - 1))
  }
}
qui <- U^2 / V
print(c(qui_quadrado = qui, gl = 1,
        p_valor = pchisq(qui, df = 1, lower.tail = FALSE)))

A saída numérica e os gráficos deste exemplo devem ser conferidos na execução do script R; não foram reproduzidos neste ambiente.

Resultados e interpretação

O código apresenta uma sugestão de aplicação; a análise deve ser adaptada aos dados e ao objetivo do estudo.

Nota metodológica

Implementação didática direta para dois grupos com censura à direita; não utilizar survdiff(rho=1) como sinônimo exato de Gehan–Breslow.
