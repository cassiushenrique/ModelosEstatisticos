Teste generalizado de Wilcoxon–Gehan

Compara grupos com tempos censurados usando ponderação pelo número de indivíduos em risco, dando mais peso a tempos iniciais.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Compara grupos com tempos censurados usando ponderação pelo número de indivíduos em risco, dando mais peso a tempos iniciais.

02 · Quais são os pressupostos e como verificá-los?

Unidades independentes, censura não informativa, tempos e status corretos; ponderação previamente escolhida.

03 · Qual a estatística de teste?

Hipóteses

H₀: distribuições de sobrevivência iguais; H₁: diferentes.

Estatística, estimador ou critério

U=∑ₜ n(t)[O₁(t)−E₁(t)], V=∑ₜ n(t)²Var[O₁(t)]; χ²=U²/V aproximadamente χ²₁.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05: evidência de diferença ponderada nas curvas; comparação com log-rank depende do padrão temporal de efeitos.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: survival. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Tempos clínicos censurados survival::lung usados como ilustração metodológica da comparação de lotes de vida útil.

R · script reproduzível
if (!requireNamespace("survival", quietly = TRUE)) install.packages("survival")
library(survival)
d <- subset(lung, !is.na(time) & !is.na(status) & !is.na(sex))
d$evento <- as.integer(d$status == 2)
d$grupo <- as.integer(d$sex == 2)
U <- 0; V <- 0
for (t in sort(unique(d$time[d$evento == 1]))) {
  risco <- d$time >= t
  evento <- d$time == t & d$evento == 1
  n <- sum(risco); n1 <- sum(risco & d$grupo == 1)
  n0 <- n - n1; dt <- sum(evento)
  o1 <- sum(evento & d$grupo == 1)
  if (n > 1) {
    U <- U + n * (o1 - dt * n1 / n)
    V <- V + n^2 * (n1 * n0 * dt * (n - dt)) / (n^2 * (n - 1))
  }
}
qui <- U^2 / V
print(c(qui_quadrado = qui, gl = 1,
        p_valor = pchisq(qui, df = 1, lower.tail = FALSE)))

Como interpretar o exemplo

Este código implementa a ponderação Gehan–Breslow n(t), distinta do rho=1 de survdiff, que usa pesos do tipo Peto–Peto. A comparação enfatiza eventos iniciais.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

Nota metodológica

Implementação didática direta para dois grupos com censura à direita; não utilizar survdiff(rho=1) como sinônimo exato de Gehan–Breslow.
