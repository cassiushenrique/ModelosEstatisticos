Separação treino–teste (holdout)

Estima desempenho fora da amostra reservando dados não usados para ajuste ou escolha de hiperparâmetros.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Estima desempenho fora da amostra reservando dados não usados para ajuste ou escolha de hiperparâmetros.

02 · Quais são os pressupostos e como verificá-los?

Independência ou divisão por grupos/tempo conforme o processo gerador; evitar vazamento de dados; pré-processamento aprendido apenas no treino.

03 · Qual a estatística de teste?

Hipóteses

Não existe H₀ inerente ao holdout; hipóteses entre modelos exigem desenho específico.

Estatística, estimador ou critério

RMSE = √mean[(y−ŷ)²] para regressão; métricas de classificação quando Y é categórica.

04 · Como interpretar o resultado, supondo 5% de significância?

A decisão não usa automaticamente 5%: menor erro em teste sugere melhor predição, com incerteza e amostra de teste consideradas.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Utiliza funções disponíveis na instalação padrão do R. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Predição de autonomia de veículos (mtcars) a partir de massa e potência.

R · script reproduzível
set.seed(2026)
i <- sample(seq_len(nrow(mtcars)), size = 22)
treino <- mtcars[i, ]; teste <- mtcars[-i, ]
ajuste <- lm(mpg ~ wt + hp, data = treino)
pred <- predict(ajuste, newdata = teste)
print(c(RMSE_teste = sqrt(mean((teste$mpg - pred)^2)),
        MAE_teste = mean(abs(teste$mpg - pred))))

Como interpretar o exemplo

O erro de teste quantifica desempenho em veículos não usados no ajuste. Um único split de 32 veículos apresenta alta variabilidade; prefira validação repetida.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

INTERPRETAÇÃO RIGOROSA

p ≥ 0,05 não prova a hipótese nula. Distinga significância estatística, magnitude e precisão. Métodos preditivos sem teste próprio devem ser avaliados fora do treino.
