Regressão por componentes principais (PCR)

Constrói componentes de X sem usar Y e ajusta a resposta por um subconjunto dessas direções.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Constrói componentes de X sem usar Y e ajusta a resposta por um subconjunto dessas direções.

02 · Quais são os pressupostos e como verificá-los?

Escalonamento quando unidades diferem; relações aproximadamente lineares nos componentes; componentes selecionados por CV e ausência de vazamento entre folds.

03 · Qual a estatística de teste?

Hipóteses

Não há teste global intrínseco à escolha de componentes; a interpretação é preditiva.

Estatística, estimador ou critério

Componentes de PCA por decomposição singular de X; selecionar ncomp pela RMSE de validação.

04 · Como interpretar o resultado, supondo 5% de significância?

Menor RMSE_CV pode favorecer um número de componentes; explicar muita variância de X não garante prever bem Y.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: pls. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Previsão da autonomia por atributos colineares de automóveis (mtcars).

R · script reproduzível
if (!requireNamespace("pls", quietly = TRUE)) install.packages("pls")
library(pls)
ajuste <- pcr(mpg ~ wt + hp + disp + qsec, data = mtcars,
              scale = TRUE, validation = "CV")
print(summary(ajuste))
print(RMSEP(ajuste, estimate = "CV"))

Como interpretar o exemplo

Compare RMSE em diferentes números de componentes, não apenas variância de X. A PCR pode perder informação preditiva em componentes de baixa variância.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

INTERPRETAÇÃO RIGOROSA
