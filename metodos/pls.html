Regressão por mínimos quadrados parciais (PLS)

Constrói direções latentes de X levando em conta a associação com Y, diferentemente da PCR.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Constrói direções latentes de X levando em conta a associação com Y, diferentemente da PCR.

02 · Quais são os pressupostos e como verificá-los?

Padronização apropriada, relação preditiva estável e escolha do número de componentes por CV; interpretação causal não é automática.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

Não há \(H_0\) único intrínseco à escolha de componentes; inferência de coeficientes requer procedimentos específicos.

Estatística de teste, estimador ou critério de otimização

\[\mathbf t_j=\mathbf X\mathbf w_j,\qquad\mathbf w_j\ \text{prioriza covariância entre }\mathbf X\text{ e }Y\]

Algoritmo de maximização sequencial de covariância entre projeções de X e Y; RMSE_CV para selecionar componentes.

04 · Como interpretar o resultado, supondo 5% de significância?

Prefira o número de componentes de menor erro validado; compare com OLS, ridge e PCR na mesma validação.

05 · Como executar no R?

Pacotes adicionais: pls. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Previsão da autonomia com atributos de veículos (mtcars).

R · executar o bloco completo
if (!requireNamespace("pls", quietly = TRUE)) install.packages("pls")
library(pls)
ajuste <- plsr(mpg ~ wt + hp + disp + qsec,
               data = mtcars, scale = TRUE, validation = "CV")
print(summary(ajuste))
print(RMSEP(ajuste, estimate = "CV"))

Interpretação do exemplo

A PLS prioriza componentes associados a mpg. A conclusão é sobre utilidade preditiva, não sobre significância de cada variável original.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.
