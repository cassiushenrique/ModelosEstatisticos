Análise log-linear

Modela contagens esperadas de tabelas multiway por modelos de Poisson sobre efeitos e interações entre fatores.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Modela contagens esperadas de tabelas multiway por modelos de Poisson sobre efeitos e interações entre fatores.

02 · Quais são os pressupostos e como verificá-los?

Contagens por células definidas corretamente; independência entre unidades amostrais; adequação de Poisson ou ajuste de sobredispersão.

03 · Qual a estatística de teste?

Hipóteses

H₀: determinado termo de interação é zero, condicional aos demais termos; H₁: é diferente de zero.

Estatística, estimador ou critério

Diferença de deviance entre modelos aninhados, com aproximação χ² sob regularidade.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05 favorece o modelo com interação; não confundir associação categórica com causalidade.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Utiliza funções disponíveis na instalação padrão do R. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Dados de sobrevivência de passageiros do Titanic como exemplo metodológico de engenharia de segurança de transportes.

R · script reproduzível
d <- as.data.frame(Titanic)
m0 <- glm(Freq ~ Class + Sex + Age + Survived,
          data = d, family = poisson())
m1 <- update(m0, . ~ . + Class:Survived)
print(anova(m0, m1, test = "Chisq"))
print(summary(m1))

Como interpretar o exemplo

A interação Class×Survived avalia se a distribuição de sobrevivência varia conforme a classe, dentro da estrutura log-linear simplificada. O conjunto é histórico, não sobre equipamentos.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
