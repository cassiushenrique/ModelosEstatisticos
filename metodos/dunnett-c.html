Dunnett C

Procedimento heterocedástico de comparações múltiplas, baseado em contraste de médias e valores críticos do módulo máximo studentizado. Não é o Dunnett clássico contra controle.

01 · O que é?

Procedimento heterocedástico de comparações múltiplas, baseado em contraste de médias e valores críticos do módulo máximo studentizado. Não é o Dunnett clássico contra controle.

02 · Quais são os pressupostos e como verificá-los?

Grupos independentes; distribuição aproximadamente normal; variâncias distintas e estimativas suficientes.

03 · Qual a estatística de teste?

Hipóteses

H₀,ij: μᵢ=μⱼ; H₁: diferentes.

Estatística, estimador ou critério

Contrastes de Welch com distribuição crítica do módulo máximo studentizado (procedimento C de Dunnett).

04 · Como interpretar o resultado, supondo 5% de significância?

Rejeição a 5% depende da calibração de Dunnett C; não a substitua por Dunnett clássico sem aviso.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: rstatix. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Quebras de fios por tensão (warpbreaks); o código utiliza Games–Howell como alternativa heterocedástica identificada.

R · script reproduzível
if (!requireNamespace("rstatix", quietly = TRUE)) install.packages("rstatix")
library(rstatix)
# Alternativa heterocedástica, NÃO é Dunnett C.
print(games_howell_test(warpbreaks, breaks ~ tension,
                        conf.level = 0.95))

Como interpretar o exemplo

Interprete apenas como Games–Howell, com IC e p ajustados para pares. Não rotule os resultados como Dunnett C.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

Nota metodológica

O procedimento exato Dunnett C não foi apresentado sem uma implementação reproduzível validada; a alternativa é declarada explicitamente.
