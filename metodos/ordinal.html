Regressão logística ordinal

Modela categorias ordenadas por logits cumulativos. Na parametrização polr, logit P(Y≤j|x)=θⱼ−xᵀβ.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Modela categorias ordenadas por logits cumulativos. Na parametrização polr, logit P(Y≤j|x)=θⱼ−xᵀβ.

02 · Quais são os pressupostos e como verificá-los?

Categorias realmente ordenadas; independência, efeitos lineares nos logits e odds proporcionais (mesma inclinação em todos os pontos de corte); avalie ajuste e plausibilidade do paralelismo.

03 · Qual a estatística de teste?

Hipóteses

H₀ⱼ: βⱼ = 0; H₁ⱼ: βⱼ ≠ 0. Pode comparar modelos aninhados por razão de verossimilhanças.

Estatística, estimador ou critério

Wald z ≈ β̂/EP(β̂); G² para comparação. A direção do efeito depende da parametrização.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05 sugere associação com deslocamento ordinal; sob polr coeficiente positivo desloca probabilidade para categorias superiores.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: MASS. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Número de marchas (3, 4, 5) ordenado por complexidade do câmbio em mtcars.

R · script reproduzível
if (!requireNamespace("MASS", quietly = TRUE)) install.packages("MASS")
library(MASS)
d <- transform(mtcars, gear = ordered(gear))
ajuste <- polr(gear ~ wt + hp, data = d, Hess = TRUE)
print(summary(ajuste))
print(predict(ajuste, newdata = d[1:5, ], type = "probs"))

Como interpretar o exemplo

Probabilidades cumulativas obedecem à ordenação 3 < 4 < 5. Verifique a plausibilidade das odds proporcionais antes de extrapolar.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
