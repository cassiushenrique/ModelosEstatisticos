SVM com kernel radial (RBF)

Obtém fronteiras não lineares por produtos internos em espaço de características implícito.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Obtém fronteiras não lineares por produtos internos em espaço de características implícito.

02 · Quais são os pressupostos e como verificá-los?

Padronização, escolha de C e gamma por CV, conjuntos representativos; risco de overfitting com n pequeno.

03 · Qual a estatística de teste?

Hipóteses

Não há H₀/teste de 5% intrínseco ao classificador.

Estatística, estimador ou critério

Otimização SVM com K(x,z)=exp(−γ||x−z||²); avalie erro em dados não vistos.

04 · Como interpretar o resultado, supondo 5% de significância?

Menor erro de teste valida o ganho de flexibilidade; não interpretar a fronteira como efeito causal.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: e1071. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Classificar veículos por cilindros a partir de massa e potência (mtcars).

R · script reproduzível
if (!requireNamespace("e1071", quietly = TRUE)) install.packages("e1071")
library(e1071)
set.seed(2026)
d <- transform(mtcars, classe = factor(cyl))
i <- unlist(lapply(split(seq_len(nrow(d)), d$classe),
                  function(z) sample(z, max(3, length(z) - 2))))
ajuste <- svm(classe ~ wt + hp, data = d[i, ],
              kernel = "radial", cost = 1, gamma = 0.5,
              scale = TRUE)
print(table(real = d$classe[-i],
            previsto = predict(ajuste, d[-i, ])))

Como interpretar o exemplo

O kernel radial permite regiões de classificação curvas. Os valores C e gamma são apenas ilustrativos e devem ser ajustados com CV em aplicação real.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
