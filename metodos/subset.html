Seleção exaustiva de subconjuntos

Compara combinações de preditores candidatos e seleciona modelos por critério predefinido, como BIC ou erro validado.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Compara combinações de preditores candidatos e seleciona modelos por critério predefinido, como BIC ou erro validado.

02 · Quais são os pressupostos e como verificá-los?

Preditores candidatos definidos, ausência de vazamento da resposta do teste, amostra suficiente; seleção influencia a validade posterior dos p-valores.

03 · Qual a estatística de teste?

Hipóteses

Cada modelo linear pode testar H₀ de seus coeficientes, mas não há H₀ único do algoritmo de seleção.

Estatística, estimador ou critério

BIC = −2ℓ(β̂)+k ln n (sob verossimilhança definida); menor BIC favorece parcimônia.

04 · Como interpretar o resultado, supondo 5% de significância?

A 5%, p-valores usuais após seleção ingênua não têm interpretação confirmatória automática; use validação e, se necessário, inferência pós-seleção.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: leaps. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Selecionar atributos de veículo relacionados à autonomia (mtcars).

R · script reproduzível
if (!requireNamespace("leaps", quietly = TRUE)) install.packages("leaps")
library(leaps)
d <- mtcars[, c("mpg", "wt", "hp", "disp", "qsec", "drat")]
ajuste <- regsubsets(mpg ~ ., data = d, nvmax = 5)
s <- summary(ajuste)
melhor <- which.min(s$bic)
print(c(modelo = melhor, BIC = s$bic[melhor]))
print(coef(ajuste, id = melhor))

Como interpretar o exemplo

O melhor BIC é um critério de ajuste penalizado, não garantia de causalidade nem desempenho fora da amostra.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
