Splines de regressão

Representam relações não lineares por funções base polinomiais por trechos, conectadas suavemente em nós.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Representam relações não lineares por funções base polinomiais por trechos, conectadas suavemente em nós.

02 · Quais são os pressupostos e como verificá-los?

Observações independentes, escolha controlada de nós/graus de liberdade e checagem de extrapolação; diagnóstico de resíduos.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

\(H_0\) opcional: componentes adicionais de flexibilidade = 0; \(H_1\): há contribuição não linear.

Estatística de teste, estimador ou critério de otimização

\[f(x)=\sum_{j=1}^m\beta_jB_j(x)\]

Teste F entre modelos lineares aninhados quando as bases e condições o permitem; desempenho CV é alternativa.

04 · Como interpretar o resultado, supondo 5% de significância?

\(p<0{,}05\) em comparação aninhada sugere flexibilidade adicional; IC de curva podem ser construídos pelo modelo, mas dependem da base especificada.

05 · Como executar no R?

Pacotes adicionais: splines (incluído no R). O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Ajustar distância de frenagem a velocidade com B-splines (cars).

R · executar o bloco completo
library(splines) # pacote recomendado, acompanha R
linear <- lm(dist ~ speed, data = cars)
flex <- lm(dist ~ bs(speed, df = 4), data = cars)
print(anova(linear, flex))
x <- data.frame(speed = seq(min(cars$speed), max(cars$speed), len = 100))
plot(dist ~ speed, data = cars)
lines(x$speed, predict(flex, x), col = "red", lwd = 2)

Interpretação do exemplo

A spline acompanha curvaturas locais, mas excesso de graus de liberdade pode ajustar ruído; valide a escolha da complexidade.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.
