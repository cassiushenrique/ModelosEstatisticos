Kappa de Fleiss

Mede acordo nominal além do acaso entre três ou mais avaliadores que classificam as mesmas unidades.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Mede acordo nominal além do acaso entre três ou mais avaliadores que classificam as mesmas unidades.

02 · Quais são os pressupostos e como verificá-los?

Categorias comuns, número de avaliações por item constante segundo definição clássica e dados comparáveis; avaliar distribuição de categorias.

03 · Qual a estatística de teste?

Hipóteses

H₀: κ_F=0; H₁: ≠0.

Estatística, estimador ou critério

κ_F=(P̄−P̄ₑ)/(1−P̄ₑ), a partir de proporções de concordância intraitem e frequências globais.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05 não implica qualidade suficiente de classificação; IC e magnitude são mais informativos.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: irr. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Três sistemas de classificação de veículos em alto/baixo desempenho, construídos de mpg, hp e wt (mtcars).

R · script reproduzível
if (!requireNamespace("irr", quietly = TRUE)) install.packages("irr")
library(irr)
ratings <- data.frame(
  A = ifelse(mtcars$mpg < median(mtcars$mpg), "alto", "baixo"),
  B = ifelse(mtcars$hp > median(mtcars$hp), "alto", "baixo"),
  C = ifelse(mtcars$wt > median(mtcars$wt), "alto", "baixo"))
print(kappam.fleiss(ratings))

Como interpretar o exemplo

O cálculo resume concordância entre sistemas didáticos distintos; discordância pode refletir escolhas de critérios, não erro dos avaliadores.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

INTERPRETAÇÃO RIGOROSA

p ≥ 0,05 não prova a hipótese nula. Distinga significância estatística, magnitude e precisão. Métodos preditivos sem teste próprio devem ser avaliados fora do treino.
