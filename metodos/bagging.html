Bagging (bootstrap aggregation)

Combina muitas árvores ajustadas sobre amostras bootstrap, reduzindo variabilidade de uma única árvore.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Combina muitas árvores ajustadas sobre amostras bootstrap, reduzindo variabilidade de uma única árvore.

02 · Quais são os pressupostos e como verificá-los?

Dados adequados ao reamostramento, árvores suficientemente diversificadas, validação out-of-bag (OOB) ou externa; não há normalidade requerida.

03 · Qual a estatística de teste?

Hipóteses

Não há H₀ padrão do bagging.

Estatística, estimador ou critério

Média das predições (regressão) ou votação (classificação) em árvores bootstrap; erro OOB estima desempenho.

04 · Como interpretar o resultado, supondo 5% de significância?

Menor erro OOB/external indica maior utilidade; não interprete a contribuição das variáveis apenas por p-valores.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: randomForest. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Predição de consumo em veículos com wt, hp e disp (mtcars).

R · script reproduzível
if (!requireNamespace("randomForest", quietly = TRUE)) install.packages("randomForest")
library(randomForest)
set.seed(2026)
ajuste <- randomForest(mpg ~ wt + hp + disp,
                       data = mtcars, mtry = 3, ntree = 400,
                       importance = TRUE)
print(ajuste)
print(importance(ajuste))

Como interpretar o exemplo

mtry=3 inclui todos os três preditores em cada divisão, reproduzindo bagging de árvores. O erro OOB é preferível ao erro no treino para avaliar previsão.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

INTERPRETAÇÃO RIGOROSA

p ≥ 0,05 não prova a hipótese nula. Distinga significância estatística, magnitude e precisão. Métodos preditivos sem teste próprio devem ser avaliados fora do treino.
