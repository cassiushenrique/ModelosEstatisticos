Redes neurais convolucionais (CNN)

Aprendem filtros locais compartilhados adequados a imagens, sinais e arranjos espaciais; usualmente não se justificam para tabelas sem estrutura espacial.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Aprendem filtros locais compartilhados adequados a imagens, sinais e arranjos espaciais; usualmente não se justificam para tabelas sem estrutura espacial.

02 · Quais são os pressupostos e como verificá-los?

Entradas com vizinhança espacial real, classes anotadas, divisão treino/teste sem vazamento espacial, quantidade de dados e regularização suficientes; exige backend computacional.

03 · Qual a estatística de teste?

Hipóteses

Não há H₀ padrão do treinamento de uma CNN; avaliação exige métrica preditiva, IC por reamostragem quando necessário.

Estatística, estimador ou critério

Camadas convolucionais, função de perda (p.ex., entropia cruzada) e otimização por gradiente; acurácia em teste, AUC etc.

04 · Como interpretar o resultado, supondo 5% de significância?

Não se usa automaticamente p<0,05. Interprete a capacidade de classificar amostras espaciais não usadas no treino.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: keras3 + TensorFlow (instalação adicional). Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Classificação de patches 5×5 de um mapa de elevação (volcano, conjunto disponível no R), analogia à detecção de regiões topográficas elevadas.

R · script reproduzível
# Requer Python/TensorFlow configurados: executar UMA VEZ,
# antes da primeira utilização: keras3::install_keras()
if (!requireNamespace("keras3", quietly = TRUE)) install.packages("keras3")
library(keras3)
set.seed(2026)
mapa <- as.matrix(volcano)
pos <- expand.grid(i = 3:(nrow(mapa)-2), j = 3:(ncol(mapa)-2))
pos <- pos[sample.int(nrow(pos), 600), ]
x <- array(0, dim = c(600, 5, 5, 1))
y <- numeric(600)
for (k in seq_len(600)) {
  i <- pos$i[k]; j <- pos$j[k]
  x[k,,,1] <- mapa[(i-2):(i+2), (j-2):(j+2)] / 200
  x[k,3,3,1] <- 0  # mascara altura central (alvo)
  y[k] <- as.integer(mapa[i,j] > median(mapa))
}
i <- sample.int(600, 480)
modelo <- keras_model_sequential(input_shape = c(5, 5, 1)) |>
  layer_conv_2d(filters = 8, kernel_size = 3, activation = "relu") |>
  layer_flatten() |>
  layer_dense(units = 1, activation = "sigmoid")
modelo |> compile(optimizer = "adam", loss = "binary_crossentropy",
                  metrics = c("accuracy"))
modelo |> fit(x[i,,, , drop = FALSE], y[i], epochs = 12,
              batch_size = 32, verbose = 0)
print(modelo |> evaluate(x[-i,,, , drop = FALSE], y[-i], verbose = 0))

Como interpretar o exemplo

A classificação usa apenas a vizinhança do ponto central; o pixel alvo foi ocultado para impedir vazamento trivial. Patches próximos ainda compartilham pixels: em aplicação real, separe regiões espaciais contíguas no treino e no teste.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

Nota metodológica

A CNN requer backend TensorFlow/Python, não incluído na instalação padrão do R. Os exemplos simples funcionam em R; este exemplo avançado exige instalação adicional e validação espacial apropriada.

INTERPRETAÇÃO RIGOROSA

p ≥ 0,05 não prova a hipótese nula. Distinga significância estatística, magnitude e precisão. Métodos preditivos sem teste próprio devem ser avaliados fora do treino.
