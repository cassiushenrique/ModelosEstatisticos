01 · O que é?

Reconhece padrões locais em imagens e sinais para realizar previsões ou classificações.

02 · Pressupostos e como verificá-los

  • Entradas com vizinhança espacial real, classes anotadas, divisão treino/teste sem vazamento espacial, quantidade de dados e regularização suficientes.
  • Exige backend computacional.

Confira o delineamento da pesquisa e os gráficos exploratórios. A validade inferencial depende dos pressupostos do modelo, não apenas do resultado de um teste diagnóstico.

03 · Hipóteses e estatística de teste

Hipóteses

Não há teste de hipótese nula intrínseco a este procedimento. A avaliação deve considerar o objetivo de estimação, a incerteza apropriada ou o desempenho em dados não utilizados no ajuste.

Estatística, estimador ou critério de ajuste

\[(W*K)_{ij}=\sum_{u,v}W_{uv}\,K_{i+u,j+v}\]

Em que:

\(\mathbf x\)
vetor de entradas
\(\mathbf W\)
matriz de pesos ajustáveis
\(\phi\)
função de ativação
\(\widehat y\)
saída predita pela rede

Camadas convolucionais, função de perda (p.ex., entropia cruzada) e otimização por gradiente; acurácia em teste, AUC etc.

Os valores amostrais são obtidos diretamente dos dados; os estimadores, pesos ou coeficientes específicos são calculados pelas funções do R indicadas no exemplo. Não substitua parâmetros desconhecidos por valores arbitrários.

04 · Como interpretar os resultados?

Não se usa automaticamente \(p<0{,}05\) . Interprete a capacidade de classificar amostras espaciais não usadas no treino.

Priorize o desempenho preditivo ou a estabilidade do ajuste. Quando não houver teste intrínseco, não interprete a métrica como valor-p nem aplique automaticamente o nível de 5%.

06 · Exemplo de aplicação

Contexto dos dados

A matriz volcano contém elevações topográficas em uma grade regular, com estrutura espacial.

Objetivo da análise

Classificação de patches \(5\times5\) de um mapa de elevação (volcano, conjunto disponível no R), analogia à detecção de regiões topográficas elevadas.

R · executar o bloco completo 
# Redes neurais convolucionais (CNN) ----

# Ajuste e resultados ----
if (!requireNamespace("keras3", quietly = TRUE)) install.packages("keras3")
library(keras3)
set.seed(2026)
mapa <- as.matrix(volcano)
pos <- expand.grid(i = 3:(nrow(mapa)-2), j = 3:(ncol(mapa)-2))
pos <- pos[sample.int(nrow(pos), 600), ]
x <- array(0, dim = c(600, 5, 5, 1))
y <- numeric(600)
for (k in seq_len(600)) {
  i <- pos$i[k]; j <- pos$j[k]
  x[k,,,1] <- mapa[(i-2):(i+2), (j-2):(j+2)] / 200
  x[k,3,3,1] <- 0  # mascara altura central (alvo)
  y[k] <- as.integer(mapa[i,j] > median(mapa))
}
i <- sample.int(600, 480)
modelo <- keras_model_sequential(input_shape = c(5, 5, 1)) |>
  layer_conv_2d(filters = 8, kernel_size = 3, activation = "relu") |>
  layer_flatten() |>
  layer_dense(units = 1, activation = "sigmoid")
modelo |> compile(optimizer = "adam", loss = "binary_crossentropy",
                  metrics = c("accuracy"))
modelo |> fit(x[i,,, , drop = FALSE], y[i], epochs = 12,
              batch_size = 32, verbose = 0)
print(modelo |> evaluate(x[-i,,, , drop = FALSE], y[-i], verbose = 0))

# Visualização e diagnóstico ----
image(volcano, main = "Mapa de elevações")

A saída numérica e os gráficos deste exemplo devem ser conferidos na execução do script R; não foram reproduzidos neste ambiente.

Resultados e interpretação

O código apresenta uma sugestão de aplicação; a análise deve ser adaptada aos dados e ao objetivo do estudo.

Nota metodológica

A CNN requer backend TensorFlow/Python, não incluído na instalação padrão do R. Os exemplos simples funcionam em R; este exemplo avançado exige instalação adicional e validação espacial apropriada.

Nota metodológica

A demonstração usa dados espaciais com vizinhanças sobrepostas. Para avaliação rigorosa, separe regiões espaciais independentes e impeça vazamento de informações.
