Regressão lasso

Regularização L1 que pode zerar coeficientes e simultaneamente selecionar variáveis.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Regularização L1 que pode zerar coeficientes e simultaneamente selecionar variáveis.

02 · Quais são os pressupostos e como verificá-los?

Padronização, amostra suficiente e estabilidade de seleção; preditores correlacionados podem gerar escolhas arbitrárias; \(\lambda\) validado.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

Não há p-valores clássicos válidos produzidos automaticamente após seleção L1.

Estatística de teste, estimador ou critério de otimização

\[\widehat{\boldsymbol\beta}=\underset{\boldsymbol\beta}{\operatorname{argmin}}\left\{\operatorname{RSS}(\boldsymbol\beta)+\lambda\sum_{j=1}^{p}|\beta_j|\right\}\]

04 · Como interpretar o resultado, supondo 5% de significância?

Variáveis com coeficientes não nulos foram selecionadas pelo algoritmo; isso não demonstra significância a 5%.

05 · Como executar no R?

Pacotes adicionais: glmnet. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Predição de consumo de veículos a partir de várias medidas (mtcars).

R · executar o bloco completo
if (!requireNamespace("glmnet", quietly = TRUE)) install.packages("glmnet")
library(glmnet)
set.seed(2026)
x <- model.matrix(mpg ~ wt + hp + disp + qsec + drat, mtcars)[, -1]
y <- mtcars$mpg
ajuste <- cv.glmnet(x, y, alpha = 1, nfolds = 5)
print(coef(ajuste, s = "lambda.min"))
plot(ajuste)

Interpretação do exemplo

Coeficientes zerados são excluídos sob a penalização, não “estatisticamente insignificantes”; avalie estabilidade e desempenho externo.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.

Nota metodológica

A seleção de preditores por LASSO não constitui um teste de significância dos coeficientes selecionados.
