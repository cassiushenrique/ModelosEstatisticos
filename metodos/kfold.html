Validação cruzada k-fold

Divide o conjunto em k partes; cada parte é predita por um modelo ajustado nas outras k−1 partes.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Divide o conjunto em k partes; cada parte é predita por um modelo ajustado nas outras k−1 partes.

02 · Quais são os pressupostos e como verificá-los?

Folhas independentes ou adequadas a grupos/tempo; toda seleção, escalonamento e ajuste de hiperparâmetros ocorrer dentro de cada treino.

03 · Qual a estatística de teste?

Hipóteses

Nenhum teste de hipóteses intrínseco.

Estatística, estimador ou critério

CV-MSE = (1/n)∑(yᵢ−ŷᵢ,−fold(i))²; RMSE_CV é sua raiz.

04 · Como interpretar o resultado, supondo 5% de significância?

Menor RMSE_CV indica melhor desempenho estimado, não “significância a 5%”. Para comparar modelos, use desenhos emparelhados/repetidos apropriados.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Utiliza funções disponíveis na instalação padrão do R. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Validação de regressão da autonomia de veículos em mtcars.

R · script reproduzível
set.seed(2026)
n <- nrow(mtcars); k <- 5
fold <- sample(rep(seq_len(k), length.out = n))
pred <- rep(NA_real_, n)
for (j in seq_len(k)) {
  ajuste <- lm(mpg ~ wt + hp, data = mtcars[fold != j, ])
  pred[fold == j] <- predict(ajuste, mtcars[fold == j, ])
}
print(c(RMSE_CV = sqrt(mean((mtcars$mpg - pred)^2)),
        MAE_CV = mean(abs(mtcars$mpg - pred))))

Como interpretar o exemplo

Todas as observações são previstas fora da dobra utilizada para ajuste. O resultado resume o erro médio da regra de regressão proposta.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
