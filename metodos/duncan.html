06 · COMPARAÇÕES MÚLTIPLASE-book

Duncan

Procedimento de amplitudes múltiplas stepwise, relativamente liberal, para grupos após ANOVA.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Procedimento de amplitudes múltiplas stepwise, relativamente liberal, para grupos após ANOVA.

02 · Quais são os pressupostos e como verificá-los?

Grupos independentes; variância residual comum e erros aproximadamente normais.

03 · Qual a estatística de teste?

Hipóteses

H₀: igualdade das médias entre grupos ou subconjuntos examinados.

Estatística, estimador ou critério

Amplitude studentizada com limiares dependentes do número de médias no intervalo ordenado.

04 · Como interpretar o resultado, supondo 5% de significância?

As letras indicam separações segundo Duncan, mas o método pode inflar erro familiar; não reportar como se controlasse FWER=5%.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: agricolae. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Comparações de tensões de fiação para quebras médias (warpbreaks).

R · script reproduzível
if (!requireNamespace("agricolae", quietly = TRUE)) install.packages("agricolae")
library(agricolae)
modelo <- aov(breaks ~ tension, data = warpbreaks)
resultado <- duncan.test(modelo, "tension", alpha = 0.05)
print(resultado$groups)

Como interpretar o exemplo

Tensões em grupos de letras distintos são consideradas diferentes pelo procedimento, mas há maior risco de falsos positivos que em Tukey/Holm.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

Nota metodológica

Duncan não controla, em geral, a taxa de erro por família no nível nominal; isto é essencial para interpretação.
