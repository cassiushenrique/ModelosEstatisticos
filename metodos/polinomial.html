Regressão polinomial

Estende regressão linear nos coeficientes com potências de preditores para capturar curvatura na média condicional.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Estende regressão linear nos coeficientes com potências de preditores para capturar curvatura na média condicional.

02 · Quais são os pressupostos e como verificá-los?

Independência, forma funcional apropriada e diagnóstico de resíduos; evitar extrapolação e grau excessivo; considerar escala/centragem numérica.

03 · Qual a estatística de teste?

Hipóteses

H₀: β₂=0 ao comparar grau 2 versus grau 1; H₁: β₂≠0.

Estatística, estimador ou critério

t do coeficiente quadrático ou teste F parcial entre modelos aninhados.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05 para termo adicional sugere curvatura sob modelo paramétrico; compare também erro fora da amostra e IC de previsão.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Utiliza funções disponíveis na instalação padrão do R. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Distância de frenagem em função da velocidade (cars).

R · script reproduzível
m1 <- lm(dist ~ speed, data = cars)
m2 <- lm(dist ~ speed + I(speed^2), data = cars)
print(anova(m1, m2))
print(confint(m2))
x <- data.frame(speed = seq(min(cars$speed), max(cars$speed), len = 100))
plot(dist ~ speed, data = cars)
lines(x$speed, predict(m2, x), col = "red", lwd = 2)

Como interpretar o exemplo

A distância de frenagem cresce tipicamente de modo não linear com a velocidade. Verifique o teste F do termo quadrático, a adequação dos resíduos e a plausibilidade física.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
