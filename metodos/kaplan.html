Estimador Kaplan–Meier

Estima a função de sobrevivência S(t)=P(T>t) com observações censuradas à direita.

01 · O que é?

Estima a função de sobrevivência S(t)=P(T>t) com observações censuradas à direita.

02 · Quais são os pressupostos e como verificá-los?

Censura não informativa em relação ao tempo de falha (sob condicionamento pertinente); unidades independentes; eventos/censuras codificados corretamente.

03 · Qual a estatística de teste?

Hipóteses

Não se aplica H₀ para a simples estimação de S(t); testes entre grupos são separados.

Estatística, estimador ou critério

Ŝ(t)=∏_{tⱼ≤t}(1−dⱼ/nⱼ), produto limite; variância de Greenwood e IC transformados.

04 · Como interpretar o resultado, supondo 5% de significância?

Interprete Ŝ(t) como fração esperada sem evento após t sob condições de amostragem. IC95% quantifica incerteza, não é teste por si só.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: survival. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Tempos censurados do pacote survival::lung, demonstrando o procedimento transferível a vida útil de equipamentos.

R · script reproduzível
if (!requireNamespace("survival", quietly = TRUE)) install.packages("survival")
library(survival)
modelo <- survfit(Surv(time, status == 2) ~ sex,
                 data = lung, conf.type = "log-log")
print(summary(modelo))
plot(modelo, col = c("#12372A", "#C68A3B"), lwd = 2,
     xlab = "Tempo", ylab = "Sobrevivência estimada")

Como interpretar o exemplo

Uma queda da curva corresponde a eventos observados; marcas de censura não implicam falha. Dados originais são clínicos, mas o estimador se aplica a tempos até falha de componentes.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

Nota metodológica

A base lung é clínica; seu uso é metodológico, não uma descrição de falhas mecânicas.
