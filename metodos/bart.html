Bayesian additive regression trees (BART)

Combina árvores regularizadas num modelo Bayesiano aditivo, produzindo amostras a posteriori de predições e, conforme formulação, da variância de erro.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Combina árvores regularizadas num modelo Bayesiano aditivo, produzindo amostras a posteriori de predições e, conforme formulação, da variância de erro.

02 · Quais são os pressupostos e como verificá-los?

Prioris de árvores e ruído adequadas, MCMC com convergência examinada, validação externa e desenho amostral apropriado.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

Não há \(H_0\) frequentista padrão; inferência é via distribuição posterior de funções preditivas.

Estatística de teste, estimador ou critério de otimização

\[f(\mathbf x)=\sum_{t=1}^{T}g(\mathbf x;\mathcal T_t,\mathcal M_t)\]

04 · Como interpretar o resultado, supondo 5% de significância?

Um intervalo de credibilidade 95% expressa incerteza posterior sob o modelo/priori; não é IC frequentista nem teste de 5% por padrão.

05 · Como executar no R?

Pacotes adicionais: BART. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Predição da autonomia por massa e potência de automóveis (mtcars).

R · executar o bloco completo
if (!requireNamespace("BART", quietly = TRUE)) install.packages("BART")
library(BART)
set.seed(2026)
X <- as.matrix(mtcars[, c("wt", "hp")]); y <- mtcars$mpg
ajuste <- wbart(x.train = X, y.train = y, x.test = X[1:5, ],
                ntree = 30, nskip = 100, ndpost = 300,
                printevery = 1000)
print(ajuste$yhat.test.mean)
print(apply(ajuste$yhat.test, 2, quantile, c(0.025, 0.975)))

Interpretação do exemplo

As previsões e intervalos são a posteriori para as cinco observações fornecidas em x.test; estas também estavam no treino, portanto não medem erro externo.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.
