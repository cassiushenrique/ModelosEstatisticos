Regressão binomial negativa

Alternativa para contagens com superdispersão: na parametrização NB2, Var(Y|x)=μ+μ²/θ.

Ver aplicação em R ↓Baixar script .R ↓

01 · O que é?

Alternativa para contagens com superdispersão: na parametrização NB2, Var(Y|x)=μ+μ²/θ.

02 · Quais são os pressupostos e como verificá-los?

Contagens não negativas; independência; média log-linear; avaliar excesso de zeros, estrutura de dependência e dispersão.

03 · Qual a estatística de teste?

Hipóteses

H₀: βⱼ=0; H₁: βⱼ≠0; a escolha de Poisson versus NB requer cuidado porque θ→∞ está no limite do espaço paramétrico.

Estatística, estimador ou critério

Wald z para β; G² para preditores em modelos aninhados sob regularidade; exp(β) é razão de médias condicionais.

04 · Como interpretar o resultado, supondo 5% de significância?

p < 0,05 sugere associação com a contagem; intervalos de confiança das razões de médias são obtidos exponenciando IC de β.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: MASS. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Quebras de fios em manufatura têxtil (warpbreaks).

R · script reproduzível
if (!requireNamespace("MASS", quietly = TRUE)) install.packages("MASS")
library(MASS)
ajuste <- glm.nb(breaks ~ tension + wool, data = warpbreaks)
print(summary(ajuste))
print(exp(cbind(razao_medias = coef(ajuste),
                confint.default(ajuste))))
print(ajuste$theta)

Como interpretar o exemplo

θ representa dispersão adicional: valores menores significam maior variância relativa à média. Compare diagnósticos e desempenho com Poisson, não apenas o valor-p.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.
