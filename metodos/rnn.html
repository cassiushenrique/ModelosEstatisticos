Redes neurais recorrentes (RNN)

Processam sequências preservando dependências temporais por estados ocultos que combinam entrada atual e informação anterior.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Processam sequências preservando dependências temporais por estados ocultos que combinam entrada atual e informação anterior.

02 · Quais são os pressupostos e como verificá-los?

Ordem temporal real, treino anterior ao teste, escalonamento apenas com treino, janelas que não vazem informação futura e validação temporal.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

Sem \(H_0\) de significância intrínseco ao treinamento; desempenho por RMSE/MAE fora da amostra temporal.

Estatística de teste, estimador ou critério de otimização

\[\mathbf h_t=\phi(\mathbf W_x\mathbf x_t+\mathbf W_h\mathbf h_{t-1}+\mathbf b)\]

04 · Como interpretar o resultado, supondo 5% de significância?

Avalie erro em períodos futuros não usados no treino; \(p<0{,}05\) não representa qualidade da previsão.

05 · Como executar no R?

Pacotes adicionais: keras3 + TensorFlow (instalação adicional). O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Previsão de passageiros mensais (AirPassengers, R base) como análogo de demanda de sistemas de transporte.

R · executar o bloco completo
# Requer Python/TensorFlow configurados: uma vez,
# antes da primeira utilização: keras3::install_keras()
if (!requireNamespace("keras3", quietly = TRUE)) install.packages("keras3")
library(keras3)
set.seed(2026)
s <- as.numeric(log(AirPassengers))
centro <- mean(s[1:100]); escala <- sd(s[1:100])
z <- (s - centro) / escala
janela <- 12
X <- array(0, c(length(z) - janela, janela, 1))
Y <- numeric(length(z) - janela)
for (i in seq_along(Y)) {
  X[i,,1] <- z[i:(i+janela-1)]
  Y[i] <- z[i+janela]
}
tr <- 1:100; te <- 101:length(Y)
modelo <- keras_model_sequential(input_shape = c(janela, 1)) |>
  layer_simple_rnn(units = 12, activation = "tanh") |>
  layer_dense(units = 1)
modelo |> compile(optimizer = "adam", loss = "mse")
modelo |> fit(X[tr,,,drop=FALSE], Y[tr], epochs = 25,
              batch_size = 16, verbose = 0)
pred <- as.numeric(modelo |> predict(X[te,,,drop=FALSE], verbose = 0))
print(c(RMSE_log_padronizado = sqrt(mean((Y[te] - pred)^2))))

Interpretação do exemplo

A divisão é temporal; apenas meses futuros são usados em teste. A previsão utiliza sazonalidade de 12 meses, mas a RNN simples deve ser comparada com referências sazonais clássicas.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.

Nota metodológica

Exige backend TensorFlow/Python e treinamento computacional. Dependência temporal obriga avaliar janelas e evitar partição aleatória.

Nota metodológica

Na predição temporal, a avaliação precisa respeitar a ordem cronológica. O exemplo exige instalação e configuração do backend TensorFlow.
