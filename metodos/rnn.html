Redes neurais recorrentes (RNN)

Analisa sequências temporais para prever comportamentos ou eventos futuros.

Ver exemplo em R ↓ Baixar script .R ↓

01 · O que é?

Analisa sequências temporais para prever comportamentos ou eventos futuros.

02 · Pressupostos e como verificá-los

  • Ordem temporal real.
  • treino anterior ao teste.
  • escalonamento apenas com treino.
  • janelas que não vazem informação futura e validação temporal.

Confira o delineamento da pesquisa e os gráficos exploratórios. A validade inferencial depende dos pressupostos do modelo, não apenas do resultado de um teste diagnóstico.

03 · Hipóteses e estatística de teste

Hipóteses

Não há teste de hipótese nula intrínseco a este procedimento. A avaliação deve considerar o objetivo de estimação, a incerteza apropriada ou o desempenho em dados não utilizados no ajuste.

Estatística, estimador ou critério de ajuste

\[\mathbf h_t=\phi(\mathbf W_x\mathbf x_t+\mathbf W_h\mathbf h_{t-1}+\mathbf b)\]

Em que:

\(\mathbf x\)
vetor de entradas
\(\mathbf W\)
matriz de pesos ajustáveis
\(\phi\)
função de ativação
\(\widehat y\)
saída predita pela rede

Os valores amostrais são obtidos diretamente dos dados; os estimadores, pesos ou coeficientes específicos são calculados pelas funções do R indicadas no exemplo. Não substitua parâmetros desconhecidos por valores arbitrários.

04 · Como interpretar os resultados?

Avalie erro em períodos futuros não usados no treino; \(p<0{,}05\) não representa qualidade da previsão.

Priorize o desempenho preditivo ou a estabilidade do ajuste. Quando não houver teste intrínseco, não interprete a métrica como valor-p nem aplique automaticamente o nível de 5%.

06 · Exemplo de aplicação

Contexto dos dados

A série AirPassengers representa passageiros mensais de companhias aéreas e contém tendência e sazonalidade.

Objetivo da análise

Previsão de passageiros mensais (AirPassengers, R base) como análogo de demanda de sistemas de transporte.

R · executar o bloco completo 
# Redes neurais recorrentes (RNN) ----

# Ajuste e resultados ----
if (!requireNamespace("keras3", quietly = TRUE)) install.packages("keras3")
library(keras3)
set.seed(2026)
s <- as.numeric(log(AirPassengers))
centro <- mean(s[1:100]); escala <- sd(s[1:100])
z <- (s - centro) / escala
janela <- 12
X <- array(0, c(length(z) - janela, janela, 1))
Y <- numeric(length(z) - janela)
for (i in seq_along(Y)) {
  X[i,,1] <- z[i:(i+janela-1)]
  Y[i] <- z[i+janela]
}
tr <- 1:100; te <- 101:length(Y)
modelo <- keras_model_sequential(input_shape = c(janela, 1)) |>
  layer_simple_rnn(units = 12, activation = "tanh") |>
  layer_dense(units = 1)
modelo |> compile(optimizer = "adam", loss = "mse")
modelo |> fit(X[tr,,,drop=FALSE], Y[tr], epochs = 25,
              batch_size = 16, verbose = 0)
pred <- as.numeric(modelo |> predict(X[te,,,drop=FALSE], verbose = 0))
print(c(RMSE_log_padronizado = sqrt(mean((Y[te] - pred)^2))))

# Visualização e diagnóstico ----
plot(AirPassengers, xlab = "Ano", ylab = "Passageiros", main = "Série mensal")

A saída numérica e os gráficos deste exemplo devem ser conferidos na execução do script R; não foram reproduzidos neste ambiente.

Resultados e interpretação

O código apresenta uma sugestão de aplicação; a análise deve ser adaptada aos dados e ao objetivo do estudo.

Nota metodológica

Exige backend TensorFlow/Python e treinamento computacional. Dependência temporal obriga avaliar janelas e evitar partição aleatória.

Nota metodológica

Na predição temporal, a avaliação precisa respeitar a ordem cronológica. O exemplo exige instalação e configuração do backend TensorFlow.
