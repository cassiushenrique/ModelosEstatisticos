Regressão local (LOESS)

Ajusta regressões em vizinhanças locais ponderadas, permitindo curvas suaves sem modelo global paramétrico.

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Ajusta regressões em vizinhanças locais ponderadas, permitindo curvas suaves sem modelo global paramétrico.

02 · Quais são os pressupostos e como verificá-los?

Densidade de dados local suficiente, escolha de span, sensibilidade a outliers e extrapolação; não tratar valores previstos como leis físicas.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

Não há \(H_0\) intrínseca à predição LOESS.

Estatística de teste, estimador ou critério de otimização

\[\widehat f(x_0)=\underset{a,b}{\operatorname{argmin}}\sum_i w_i(x_0)[y_i-a-b(x_i-x_0)]^2\]

Minimização ponderada local com pesos função da distância; span define tamanho da vizinhança.

04 · Como interpretar o resultado, supondo 5% de significância?

Compare curvas para diferentes span e desempenho de validação; \(\alpha=5\%\) só entra se um procedimento inferencial adicional for especificado.

05 · Como executar no R?

Usa funções da instalação padrão do R. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Distância de frenagem versus velocidade no conjunto cars.

R · executar o bloco completo
ajuste <- loess(dist ~ speed, data = cars, span = 0.7)
x <- data.frame(speed = seq(min(cars$speed), max(cars$speed), len = 100))
plot(dist ~ speed, data = cars)
lines(x$speed, predict(ajuste, newdata = x), col = "red", lwd = 2)
print(summary(ajuste))

Interpretação do exemplo

Span menor acompanha flutuações locais; span maior produz curva mais lisa. Não extrapole LOESS fora da faixa observada.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.
