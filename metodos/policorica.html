Correlação policórica

01 · O que é?

Estima a correlação entre latentes normais bivariadas representadas por categorias ordinais.

02 · Quais são os pressupostos e como verificá-los?

Observações independentes; categorias ordinalmente consistentes; modelo de limiares e normalidade latente plausíveis; células com informação suficiente.

03 · Qual a estatística de teste?

Hipóteses

H₀: ρ_latente = 0; H₁: ≠ 0, quando inferência específica é calculada.

Estatística, estimador ou critério

Estimador de correlação latente por máxima verossimilhança a partir dos limiares ordinais.

04 · Como interpretar o resultado, supondo 5% de significância?

Interprete a associação latente; não assuma automaticamente que ela corresponde à correlação observada nem que há p-valor.

05 · Como executar no R?

O bloco do exemplo contém todos os comandos necessários. Pacotes adicionais: psych. Quando necessário, o script instala o pacote ausente e carrega a biblioteca com library().

É possível copiar os comandos ou baixar o arquivo .R completo. Execute o script inteiro no RStudio, preferencialmente com uma sessão limpa.

06 · Exemplo de aplicação na engenharia

Contexto e dados

Categorias de potência e consumo de veículos (mtcars), tomadas como indicadores ordinais.

R · script reproduzível
if (!requireNamespace("psych", quietly = TRUE)) install.packages("psych")
library(psych)
X <- data.frame(
 potencia = ordered(cut(mtcars$hp, breaks = 3, labels = FALSE)),
 autonomia = ordered(cut(mtcars$mpg, breaks = 3, labels = FALSE)))
print(table(X))
print(polychoric(X)$rho)

Como interpretar o exemplo

O sinal da estimativa descreve a relação postulada entre os indicadores latentes; o recorte das faixas influencia a informação disponível.

Caso algum pacote não esteja instalado, o primeiro comando install.packages() exige conexão à internet. Os dados usados estão disponíveis no R ou nos pacotes identificados.

Nota metodológica

As faixas do exemplo são discretizações didáticas de variáveis originalmente contínuas; não se recomenda discretizar dados contínuos sem justificativa.
