Regressão de Cox

Modelo semiparamétrico para tempo até evento: \(\lambda(t\mid x)=\lambda_0(t)e^{\mathbf x^\top\boldsymbol\beta}\).

Ver exemplo em R ↓Baixar script .R ↓

01 · O que é?

Modelo semiparamétrico para tempo até evento: \(\lambda(t\mid x)=\lambda_0(t)e^{\mathbf x^\top\boldsymbol\beta}\).

02 · Quais são os pressupostos e como verificá-los?

Censura não informativa condicional, independência entre unidades, proporcionalidade dos riscos, covariáveis adequadamente especificadas; verifique resíduos de Schoenfeld e influência.

03 · Qual a estatística de teste?

Hipóteses ou objetivo inferencial

\(H_0\): \(\beta_{j}=0\) (HR=1); \(H_1\): \(\beta_{j}\neq0\); testes global Wald, escore ou razão de verossimilhanças parcial.

Estatística de teste, estimador ou critério de otimização

\[h(t\mid\mathbf x)=h_0(t)\exp(\mathbf x^\top\boldsymbol\beta),\qquad HR=e^{\beta_j}\]

Intervalo de confiança de 95% (quando aplicável)

\[IC_{95\%}(HR_j)\approx\exp\!\left[\widehat\beta_j\pm1{,}96\operatorname{EP}(\widehat\beta_j)\right]\]

04 · Como interpretar o resultado, supondo 5% de significância?

\(p<0{,}05\): evidência de associação com a taxa instantânea de evento. HR não é razão de probabilidades de falha nem diferença de tempo médio.

05 · Como executar no R?

Pacotes adicionais: survival. O exemplo abaixo é completo e inclui as chamadas de library() quando necessárias. Execute os comandos na sequência e confira os diagnósticos antes de interpretar inferências.

Use o botão Copiar código ou baixe o script .R. Para os métodos que exigem bibliotecas adicionais, a primeira execução pode realizar a instalação por install.packages().

06 · Exemplo de aplicação na engenharia

Demonstração metodológica com survival::lung (dados clínicos de tempos censurados), diretamente transferível à análise de tempo até falha em confiabilidade.

R · executar o bloco completo
if (!requireNamespace("survival", quietly = TRUE)) install.packages("survival")
library(survival)
d <- na.omit(lung[, c("time", "status", "age", "sex")])
ajuste <- coxph(Surv(time, status == 2) ~ age + sex, data = d)
print(summary(ajuste))
print(cox.zph(ajuste))
print(exp(confint(ajuste)))

Interpretação do exemplo

A análise é de sobrevivência clínica na base original. Na engenharia, substitua time por tempo até falha e status pelo indicador de falha; examine a proporcionalidade antes de usar HR constante.

Os dados são carregados de bases incluídas no R ou nos pacotes indicados. A instalação de pacotes requer conexão à internet. O exemplo usa os dados originais como aplicação, referência ou analogia de engenharia, conforme explicitado acima.

Nota metodológica

Dados disponíveis no pacote survival, mas são clínicos; não os apresente como falhas de equipamentos.

CRITÉRIO DE DECISÃO

\(p\geq0{,}05\) não prova a hipótese nula. Para modelos sem teste intrínseco, avalie o erro de predição e a estabilidade com dados não utilizados no ajuste.
